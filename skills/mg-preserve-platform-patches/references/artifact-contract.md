# Platform Audit Artifact Contract

Bind outputs to full refs. Sort platforms, API rows, routes, and occurrences deterministically.

Require every platform implementation to record source, class, bases, registration key, selection presence, missing/changed APIs, inherited APIs, owner, disposition, and tests. Require every raw device occurrence to record path, line, symbol, token family, route domains, classification, owner, reason, and test or external gate.

Keep extracted facts immutable and human decisions separate. Reject broad path allowlists, fixed vendor acceptance lists, missing route coverage, or blocked hardware evidence without an owner.
