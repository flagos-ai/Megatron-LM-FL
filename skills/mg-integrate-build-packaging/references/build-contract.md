# Build contract

Pin classifier refs. Stable rows derive from delta ID and path. Immutable facts include Git status/mode/hash, file kind, fork/target existence, pyproject sections/dependencies, MANIFEST rules, Docker bases/stages/args, shell syntax, imports, and route domains.

Reviewed fields are owner, requirement, target_relationship, strategy, validation_gates, external_gate, reason, and evidence. Strategies are preserve, adapt, upstream, redesign, and drop. Never rewrite facts through decisions.
