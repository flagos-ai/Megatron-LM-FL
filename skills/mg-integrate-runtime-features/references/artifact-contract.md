# Runtime Feature Artifact Contract

Bind artifacts to exact refs. Candidate rows contain immutable delta IDs, paths, actions, categories, priorities, secondary handlers, marker counts, discovered symbols, and candidate lifecycle stages.

Human decisions must record stable feature name, reviewed members, invariant, target change, strategy, owner, stage rationale, dependencies, observing tests, reviewer, approval, and skill-gap IDs. Reject unknown/duplicate deltas and silent member loss.

Acceptance requires every runtime route exactly once, zero overlapping reviewed groups, at least one execution-stage member, observing evidence, explicit approval for any REDESIGN member, and external owners for blocked tests.
