# CI/CD and Verification

Discover workflows, configs, tests, and vendors dynamically from the integrated tree. Validate YAML syntax, reusable workflow inputs/outputs, permissions, referenced scripts, matrix keys, ignored test paths, packaging configuration, and test path existence.

Use layered gates: static/AST/schema; package/import/registry; CPU; single-device CUDA; NVIDIA distributed; each discovered vendor; FlagScale end-to-end. Record unavailable hardware as an external gate with an owner and command/config, not as passed or skipped without consequence.
