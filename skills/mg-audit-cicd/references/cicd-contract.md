# CI/CD Contract

Record workflow events, permissions, runner labels, job dependencies, reusable-workflow calls, matrices, environments, secrets, conditions, timeouts, and failure controls. Syntax success is not execution success.

Resolve repository-local paths at the audited ref. Treat expressions and generated paths as dynamic and require manual evidence. Record fork-only assets explicitly.

Discover backend coverage from actual CI configs and platform/plugin manifests. Never maintain a fixed vendor list. Missing hardware is an external gate, not a pass.
